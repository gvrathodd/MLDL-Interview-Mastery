Sequence Modeling: Temporal Physics & Dynamic Memory

Why feedforward networks fail on sequential data, the Markov dilemma, and recurrent state transitions.

⏳ Why Standard MLPs Cannot Model Sequences

Consider language, audio, or financial time-series data:

  1. Variable Input Lengths: A sentence can have 3 words or 150 words. A standard MLP requires a fixed input vector size $D$. Padding to 1000 words wastes compute and breaks position semantics.
  2. Temporal Ordering & Context: The meaning of a word depends heavily on words that appeared 10 steps earlier: "The bank of the river..." vs. "The bank approved my loan...". MLPs treat input positions as independent coordinates, destroying sequential relationships.
  3. Parameter Explosion: If we concatenate a sliding window of 50 words into an MLP, the model learns separate weights for word 1, word 2, and word 50 — failing to share temporal knowledge!

1. The Concept of Recurrent Hidden Memory ($h_t$)

State Transition Formulation:

A Recurrent Neural Network (RNN) processes a sequence step-by-step, maintaining an internal hidden state vector $h_t \in \mathbb{R}^H$ that acts as a lossy compression of all historical inputs seen from time $1$ to $t$:

$$\mathbf{h_t = f_W(h_{t-1}, x_t)}$$
  • $x_t$: Current input at time step $t$.
  • $h_{t-1}$: Hidden state inherited from the previous time step $t-1$.
  • $W$: Shared weight parameters applied identically across every time step $t=1, \dots, T$.

Vanilla RNN: Forward Transitions & BPTT Unrolling

Step-by-step matrix equations, computational graph unrolling, and shared weight gradient accumulation.

🔄 Forward Recurrence Equations

At each time step $t$, the standard RNN performs a linear combination of the current input $x_t$ and previous hidden memory $h_{t-1}$, passed through a non-linear $\tanh$ activation:

$$\mathbf{h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)}$$ $$\mathbf{\hat{y}_t = \text{softmax}(W_{hy} h_t + b_y)}$$
MatrixDimensionsFunctional Role
$W_{xh}$$(H \times D)$Projects input $x_t$ into hidden representation space.
$W_{hh}$$(H \times H)$Recurrent transition matrix (temporal memory mixing).
$W_{hy}$$(C \times H)$Projects hidden state $h_t$ to class logits.

1. Backpropagation Through Time (BPTT)

Unrolling the Computational Graph:

Total sequence loss is the sum of losses across all time steps: $\mathcal{L} = \sum_{t=1}^T \mathcal{L}_t$.

Because weight matrix $W_{hh}$ is reused across every time step, its total gradient is the sum of gradients accumulated over all time steps:

$$\mathbf{\frac{\partial \mathcal{L}}{\partial W_{hh}} = \sum_{t=1}^T \sum_{k=1}^t \frac{\partial \mathcal{L}_t}{\partial h_t} \frac{\partial h_t}{\partial h_k} \frac{\partial h_k}{\partial W_{hh}}}$$

Where the key chain rule term $\frac{\partial h_t}{\partial h_k}$ tracks gradient flow backwards from step $t$ to earlier step $k$.

Mathematical Proof: Vanishing Gradients in RNNs

Bengio et al. (1994), Pascanu et al. (2013), the Jacobian chain product, and spectral radius limits.

🛑 The Fatal Flaw of Vanilla RNNs

In practice, vanilla RNNs cannot learn dependencies longer than 8 to 10 time steps. If the first word of a sentence determines the subject, an RNN fails to pass that information to the verb at step 20.

1. Complete Mathematical Derivation

Theorem: The temporal gradient decomposes into a product of $T - t$ Jacobian matrices.

Consider the derivative of hidden state $h_T$ with respect to an earlier state $h_t$:

$$\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^T \frac{\partial h_k}{\partial h_{k-1}}$$

Recall $h_k = \tanh(z_k)$ where $z_k = W_{hh} h_{k-1} + W_{xh} x_k + b_h$. The Jacobian matrix $\frac{\partial h_k}{\partial h_{k-1}}$ is:

$$\frac{\partial h_k}{\partial h_{k-1}} = \text{diag}(1 - h_k^2) \cdot W_{hh}^T$$

Substituting into the chain product:

$$\mathbf{\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^T \Big( \text{diag}(1 - h_k^2) \cdot W_{hh}^T \Big)}$$

Spectral Analysis (Pascanu et al., 2013):

  • Let the maximum eigenvalue (spectral radius) of $W_{hh}$ be $\lambda_{\max}$.
  • Since $\tanh'(z) = 1 - \tanh^2(z) \in (0, 1]$, the diagonal matrix has values $\le 1.0$.
  • The norm of the gradient product is bounded by: $$\left\| \frac{\partial h_T}{\partial h_t} \right\| \le (\lambda_{\max})^{T - t}$$

The Two Catastrophes:

  1. Vanishing Gradient ($\lambda_{\max} < 1$): As sequence length $(T - t) \to 20$, $(\lambda_{\max})^{20} \to 0$. Gradients decay exponentially to zero! The network physically cannot learn long-term temporal dependencies.
  2. Exploding Gradient ($\lambda_{\max} > 1$): As $(T - t)$ grows, $(\lambda_{\max})^{T-t} \to \infty$. Gradients explode to NaN! Solved using Gradient Clipping by Norm.

LSTM In-Depth & The Constant Error Carousel

Hochreiter & Schmidhuber (1997), the additive Cell State highway, and gate interaction calculus.

🗄️ How LSTM Cured Vanishing Gradients

In 1997, Sepp Hochreiter and Jürgen Schmidhuber introduced the Long Short-Term Memory (LSTM) architecture. Instead of overwriting hidden memory via matrix multiplication, LSTM maintains a protected conveyor belt — the Cell State ($C_t$) — regulated by 3 non-linear gates.

1. The Four Mathematical Steps of an LSTM Unit

  1. Forget Gate ($f_t$): Decides what percentage of old cell memory to discard: $$\mathbf{f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \in (0, 1)^H}$$ ($f_t = 0 \implies$ completely erase; $f_t = 1 \implies$ completely retain).

  2. Input Gate ($i_t$) & Candidate Memory ($\tilde{C}_t$): Decides what new information to add: $$\mathbf{i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \in (0, 1)^H}$$ $$\mathbf{\tilde{C}_t = \tanh(W_c [h_{t-1}, x_t] + b_c) \in (-1, 1)^H}$$

  3. Cell State Update ($C_t$): The Additive Highway! $$\mathbf{C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t}$$

  4. Output Gate ($o_t$) & Hidden State ($h_t$): Decides what to output to the next layer: $$\mathbf{o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \in (0, 1)^H}$$ $$\mathbf{h_t = o_t \odot \tanh(C_t)}$$

2. Mathematical Proof: Why LSTM Does Not Vanish Gradients

Theorem: The derivative of $C_T$ with respect to $C_t$ contains an additive identity path.

Compute the partial derivative of current cell state $C_t$ with respect to previous cell state $C_{t-1}$:

$$\frac{\partial C_t}{\partial C_{t-1}} = f_t + \frac{\partial f_t}{\partial C_{t-1}} C_{t-1} + \frac{\partial i_t}{\partial C_{t-1}} \tilde{C}_t + i_t \frac{\partial \tilde{C}_t}{\partial C_{t-1}}$$

Across $T - t$ time steps:

$$\mathbf{\frac{\partial C_T}{\partial C_t} = \prod_{k=t+1}^T f_k + \dots}$$
  • Notice the first term: It is the product of forget gates $\prod f_k$ without any matrix multiplications by $W$!
  • If the network learns to keep the forget gate open ($f_k \approx 1.0$), the gradient passes backward across 100+ time steps with zero attenuation ($\prod 1.0 = 1.0$)!
  • This uninterrupted additive mechanism is known as the Constant Error Carousel (CEC).

💡 Interview Secret: The Forget Gate Bias Trick (Jozefowicz et al., 2015)

Always initialize the forget gate bias $b_f$ to $+1.0$ or $+2.0$ (instead of 0). This forces $\sigma(b_f) \approx 0.73$ to $0.88$ at initialization, ensuring the model remembers long-term history by default until it explicitly learns to forget!

Gated Recurrent Unit (GRU): Architecture & Formulas

Kyunghyun Cho et al. (2014), merging hidden and cell states, and parameter efficiency vs. LSTM.

⚡ Streamlining the LSTM

LSTMs are powerful but computationally heavy: each cell maintains 4 separate weight matrices ($W_f, W_i, W_c, W_o$) and two distinct state vectors ($h_t$ and $C_t$).

The Gated Recurrent Unit (GRU) simplifies this by merging the cell state into the hidden state $h_t$ and combining the input and forget gates into a single Update Gate.

1. The Four Mathematical Equations of a GRU

  1. Reset Gate ($r_t$): Decides how much past memory to ignore when computing candidate state: $$\mathbf{r_t = \sigma(W_r [h_{t-1}, x_t] + b_r)}$$
  2. Update Gate ($z_t$): Acts simultaneously as both forget gate and input gate: $$\mathbf{z_t = \sigma(W_z [h_{t-1}, x_t] + b_z)}$$
  3. Candidate Hidden State ($\tilde{h}_t$): $$\mathbf{\tilde{h}_t = \tanh(W_h [r_t \odot h_{t-1}, x_t] + b_h)}$$
  4. Hidden State Interpolation ($h_t$): Linear blend between old memory and candidate state! $$\mathbf{h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t}$$

Bidirectional & Stacked Recurrent Architectures

Schuster & Paliwal (1997), future temporal context, and deep stacked RNN residual connections.

🔮 Why Left-to-Right Processing Is Insufficient

Consider Named Entity Recognition (NER) on the sentence: "Teddy Roosevelt was the 26th president of the United States."

When an RNN reads the first word "Teddy", it cannot know whether it refers to a stuffed toy bear or a US president! The disambiguating context ("president") appears 5 words in the future!

Bidirectional RNNs (BiRNN / BiLSTM) solve this by processing the sequence in both directions simultaneously.

1. The Bidirectional Architecture

Run two independent recurrent networks in parallel:

  1. Forward Hidden State ($\overrightarrow{h}_t$): Reads sequence from left to right: $t = 1 \to T$.
  2. Backward Hidden State ($\overleftarrow{h}_t$): Reads sequence from right to left: $t = T \to 1$.
  3. Combined Output Representation: Concatenate both vectors: $$\mathbf{h_t = \left[ \overrightarrow{h}_t \,;\, \overleftarrow{h}_t \right] \in \mathbb{R}^{2H}}$$

Limitation: BiRNNs require the entire sequence up-front — they cannot be used for real-time autoregressive streaming generation (where future tokens do not exist yet).

Seq2Seq & The Information Bottleneck Crisis

Sutskever et al. (2014), Encoder-Decoder translation, and why fixed-vector compression broke on long sequences.

📦 The Encoder-Decoder Framework

Machine translation maps an input sequence of length $M$ (e.g. 10 French words) to an output sequence of different length $N$ (e.g. 12 English words). In 2014, Google introduced the Sequence-to-Sequence (Seq2Seq) framework:

  1. Encoder RNN: Reads the input tokens $x_1, \dots, x_M$ step-by-step. The final hidden state $h_M$ acts as the Context Vector $c$.
  2. Decoder RNN: Takes context vector $c$ as initial hidden state ($s_0 = c$) and autoregressively generates output tokens $y_1, y_2, \dots, y_N$ one by one until an $\langle\text{EOS}\rangle$ token is emitted.

1. The Fatal Information Bottleneck

🚨 Why Seq2Seq Degraded on Sentences > 20 Words:

Consider compressing a complex 50-word legal sentence into a single 512-dimensional vector $c = h_M$. It is physically impossible for a fixed-size vector of 512 numbers to preserve all nuanced syntax, entities, and relations!

Bahdanau et al. (2014) showed that Seq2Seq translation quality (BLEU score) dropped off a cliff for sequences longer than 20 words. This crisis directly inspired the invention of the Attention Mechanism!

The Attention Revolution: Bahdanau & Luong Math

Dynamic soft alignment, context vector calculus, and eliminating the static bottleneck.

🔍 What is Attention? (First Principles)

Instead of forcing the decoder to rely on a single static vector $c = h_M$, Attention allows the decoder to look back at ALL encoder hidden states $[h_1, h_2, \dots, h_M]$ at every decoding step $t$!

When translating the French word "pomme" to "apple", the decoder focuses 98% of its attention on the specific encoder state representing "pomme".

1. The 3-Step Mathematical Formulation of Attention

  1. Compute Alignment Scores ($e_{t, i}$):
    Measures how relevant encoder state $h_i$ is to current decoder state $s_{t-1}$:
    • Bahdanau Additive Attention (1994): $$\mathbf{e_{t, i} = v_a^T \tanh(W_a s_{t-1} + U_a h_i)}$$
    • Luong Multiplicative / Dot-Product Attention (2015): $$\mathbf{e_{t, i} = s_t^T W_a h_i \quad (\text{or simple dot product: } s_t^T h_i)}$$

  2. Softmax Normalization (Attention Weights $\alpha_{t, i}$): $$\mathbf{\alpha_{t, i} = \frac{\exp(e_{t, i})}{\sum_{k=1}^M \exp(e_{t, k})}}$$ ($\sum_{i=1}^M \alpha_{t, i} = 1$, representing a valid probability distribution over input tokens).

  3. Compute Dynamic Context Vector ($c_t$): $$\mathbf{c_t = \sum_{i=1}^M \alpha_{t, i} h_i}$$

The dynamic context vector $c_t$ is concatenated with decoder hidden state $s_t$ to predict the next word $y_t$. The static bottleneck is completely eliminated!

Worked Toy Attention Walkthrough with Real Numbers

Tracing alignment scores, softmax normalization, and context vector creation by hand.

🧮 Concrete Mathematical Walkthrough

Let's manually compute attention for an input sequence of $M = 3$ tokens with 3-dimensional encoder hidden vectors:

  • Encoder token 1: $\mathbf{h}_1 = \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix}$ (e.g. representing "The")
  • Encoder token 2: $\mathbf{h}_2 = \begin{bmatrix} 0 \\ 2 \\ 0 \end{bmatrix}$ (e.g. representing "apple")
  • Encoder token 3: $\mathbf{h}_3 = \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}$ (e.g. representing "falls")

Current decoder query state: $\mathbf{q} = \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}$.

1. Step 1: Compute Dot-Product Alignment Scores

$$e_1 = \mathbf{q}^T \mathbf{h}_1 = (1 \times 1) + (1 \times 0) + (0 \times 1) = \mathbf{1.0}$$ $$e_2 = \mathbf{q}^T \mathbf{h}_2 = (1 \times 0) + (1 \times 2) + (0 \times 0) = \mathbf{2.0}$$ $$e_3 = \mathbf{q}^T \mathbf{h}_3 = (1 \times 1) + (1 \times 1) + (0 \times 0) = \mathbf{2.0}$$

Raw unnormalized scores: $\mathbf{e} = [1.0, \; 2.0, \; 2.0]$.

2. Step 2: Softmax Normalization (Attention Weights)

Exponentiate each score:

  • $e^{1.0} \approx 2.7183$
  • $e^{2.0} \approx 7.3891$
  • $e^{2.0} \approx 7.3891$

Sum of exponents $= 2.7183 + 7.3891 + 7.3891 = \mathbf{17.4965}$.

Compute Attention Weights $\alpha_i = \frac{e^{e_i}}{\sum e^{e_k}}$:

$$\alpha_1 = \frac{2.7183}{17.4965} \approx \mathbf{0.1554} \quad (15.54\%)$$ $$\alpha_2 = \frac{7.3891}{17.4965} \approx \mathbf{0.4223} \quad (42.23\%)$$ $$\alpha_3 = \frac{7.3891}{17.4965} \approx \mathbf{0.4223} \quad (42.23\%)$$

Verification: $0.1554 + 0.4223 + 0.4223 = 1.0000$.

3. Step 3: Compute the Dynamic Context Vector $\mathbf{c}$

$$\mathbf{c} = \alpha_1 \mathbf{h}_1 + \alpha_2 \mathbf{h}_2 + \alpha_3 \mathbf{h}_3$$ $$\mathbf{c} = 0.1554 \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix} + 0.4223 \begin{bmatrix} 0 \\ 2 \\ 0 \end{bmatrix} + 0.4223 \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}$$ $$\mathbf{c} = \begin{bmatrix} 0.1554 + 0 + 0.4223 \\ 0 + 0.8446 + 0.4223 \\ 0.1554 + 0 + 0 \end{bmatrix} = \mathbf{\begin{bmatrix} 0.5777 \\ 1.2669 \\ 0.1554 \end{bmatrix}}$$

Result: The context vector $\mathbf{c}$ cleanly focuses $84.5\%$ of its mass on tokens 2 and 3, blending their information to guide the decoder's next token prediction!

Production Sequence Processing: Beam Search & CTC Loss

Greedy vs. Beam Search decoding, Teacher Forcing dynamics, and CTC alignment-free loss.

🎙️ Production Sequence Decoding & Speech Recognition

In production NLP and Speech-to-Text pipelines, generating tokens greedily can lead to catastrophic dead ends. Specialized decoding and loss formulations govern production deployment.

1. Greedy Decoding vs. Beam Search

A. Greedy Decoding (Width $B=1$):

Picks the single highest probability token at each step: $y_t = \arg\max P(y \mid y_{

The Flaw: Myopic search! A globally optimal translation might start with a word that has slightly lower initial probability ($P=0.29$ vs $P=0.31$). Greedy search permanently discards that entire branch!


B. Beam Search (Beam Width $B$, typically $B=4$ to $8$):

Maintains the top $B$ most probable candidate sequence hypotheses at each step:

  1. At step $t$, expand each of the $B$ active hypotheses into all $V$ vocabulary words ($B \times V$ candidates).
  2. Compute cumulative log-probabilities: $\text{Score} = \sum_{i=1}^t \ln P(y_i \mid y_{
  3. Prune back down to only the top $B$ highest-scoring paths.
  4. Apply length normalization to prevent penalizing longer sentences: $\text{Score}_{\text{norm}} = \frac{\text{Score}}{L^\alpha}$ (typically $\alpha = 0.6$ to $0.7$).

2. Connectionist Temporal Classification (CTC Loss, Graves et al., 2006)

The Alignment Dilemma in Speech & OCR:

In speech recognition, audio has 1,000 frames of spectrogram data, but the spoken transcript is only 15 letters: "HELLO WORLD". We do not know which exact millisecond correspond to which letter!

The CTC Solution:

CTC introduces a special Blank Token ($\epsilon$) and allows repeated characters:

$$\text{Alignment: } [H, H, \epsilon, E, E, L, \epsilon, L, L, O] \xrightarrow{\text{Collapse}} \text{"HELLO"}$$

CTC uses dynamic programming to sum probabilities over all possible valid alignments that collapse to the target transcript, training speech and handwriting models with zero manual time-alignment labels!

25+ High-Frequency FAANG Interview Questions: Sequence Models

Real screening and system design questions asked at Google, Apple, Amazon, and Meta.

Part 1: RNNs, BPTT & Gradients

Q1: Why do vanilla RNNs suffer from vanishing and exploding gradients? Core

Answer: Backpropagation through time computes $\frac{\partial h_T}{\partial h_t} = \prod_{k=t+1}^T \text{diag}(1 - h_k^2) W_{hh}^T$. This is a product of $T - t$ matrices. If the spectral radius $\rho(W_{hh}) < 1$, the gradient decays exponentially to zero ($O(\lambda^{T-t}) \to 0$). If $\rho(W_{hh}) > 1$, it explodes exponentially to infinity.

Q2: How does an LSTM solve the vanishing gradient problem? What is the Constant Error Carousel? LSTM Math

Answer: The LSTM cell state update is additive: $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$. The derivative is $\frac{\partial C_t}{\partial C_{t-1}} = f_t + \dots$. If the network keeps the forget gate open ($f_t \approx 1$), gradient flows back across hundreds of time steps through the uninterrupted additive identity connection without decaying.

Q3: Why should the forget gate bias in an LSTM be initialized to +1.0 instead of 0? Best Practice

Answer: Initializing $b_f = 0$ gives $\sigma(0) = 0.5$, meaning the cell forgets 50% of its memory at every single time step. Initializing $b_f = +1.0$ (or $+2.0$) forces $\sigma(b_f) \approx 0.73$ to $0.88$, ensuring the model remembers long-term context by default from the start of training.

Q4: Compare GRU and LSTM. When would you choose GRU over LSTM? Concept

Answer: GRU merges cell state and hidden state, using only 2 gates (Reset, Update) compared to LSTM's 3 gates. GRU has 25% fewer parameters ($3 \times$ matrices vs $4 \times$), trains faster, and requires less GPU memory. Choose GRU for smaller datasets, resource-constrained edge devices, and when low inference latency is paramount.

Q5: How many parameters are in an LSTM layer with input size 100 and hidden size 256? Math

Answer: An LSTM has 4 gates ($f, i, c, o$). Each gate has weights for input ($100 \times 256$) + recurrent weights ($256 \times 256$) + bias ($256$).

Per gate: $(100 \times 256) + (256 \times 256) + 256 = 25,600 + 65,536 + 256 = 91,392$.

Total for 4 gates: $4 \times 91,392 = \mathbf{365,568 \text{ parameters}}$.

Part 2: Seq2Seq & The Attention Revolution

Q6: What is the Information Bottleneck in classical Seq2Seq models? Seq2Seq

Answer: The encoder forces the entire variable-length source sentence (e.g. 50 words) into a single fixed-size context vector $c = h_M$. Compressing complex semantics into a single vector causes severe information loss on sequences longer than 20 words, leading to degraded translations.

Q7: What is the fundamental difference between Bahdanau Attention and Luong Attention? Attention

Answer:

  • Bahdanau (Additive): Alignment score $e_{t, i} = v_a^T \tanh(W_a s_{t-1} + U_a h_i)$ uses a feedforward hidden layer to combine decoder state $s_{t-1}$ and encoder state $h_i$. Evaluated before computing $s_t$.
  • Luong (Multiplicative): Alignment score $e_{t, i} = s_t^T W_a h_i$ (or dot product $s_t^T h_i$). Evaluated after computing current decoder state $s_t$. Multiplicative attention is faster to compute via matrix multiplications.
Q8: What is Teacher Forcing and what is Exposure Bias? Training

Answer: Teacher Forcing feeds the ground truth target token $y_{t-1}^*$ as input to the decoder at step $t$ during training, rather than the model's own predicted token $\hat{y}_{t-1}$. Accelerates early training, but causes Exposure Bias: at inference time, ground truth is absent, and the model compounding errors on its own mistakes. Mitigated by Scheduled Sampling.

Q9: Why can't Bidirectional RNNs be used for autoregressive language generation? Concept

Answer: The backward RNN requires tokens from the end of the sentence to the beginning ($t = T \to 1$). During open-ended autoregressive generation, future tokens have not been generated yet, so the backward pass cannot physically execute.

Q10: How does Beam Search differ from Greedy Decoding? Decoding

Answer: Greedy decoding selects the single highest probability token at each step ($B=1$), which can prune optimal sequences early. Beam Search maintains the top $B$ cumulative sequence candidates at each step, pruning all others, finding globally superior sentence translations.

Part 3: Production & Audio/Speech Models

Q11: What is Connectionist Temporal Classification (CTC) Loss and where is it used? Speech / OCR

Answer: Used when input sequence length is much longer than output label length and alignment is unaligned (e.g. 1000 audio frames to 15 letters). CTC introduces blank tokens $\epsilon$ and sums probabilities over all valid collapsible paths using dynamic programming, avoiding manual frame-level alignment.

Q12: Why are RNNs slower to train on modern GPUs compared to Transformers? GPU Hardware

Answer: RNNs have a sequential temporal dependency: $h_t$ cannot be computed until $h_{t-1}$ finishes executing, serializing execution into $T$ sequential steps. Transformers compute attention across all $T$ tokens simultaneously via matrix multiplication ($Q K^T$), fully parallelizing across thousands of GPU CUDA cores.

Q13: How does Truncated BPTT work? Engineering

Answer: For infinitely long sequences, full BPTT would require unbounded memory and compute. Truncated BPTT executes forward passes indefinitely, but limits the backward pass to a fixed horizon $k$ steps (e.g. $k=35$), clipping backpropagation to maintain fixed $O(k)$ memory.

Q14: What is the purpose of Length Normalization in Beam Search? Math

Answer: Since cumulative score is $\sum \ln P(y_i)$ (sum of negative log probabilities), longer sentences naturally accumulate lower total scores. Length normalization divides by $L^\alpha$, preventing the model from disproportionately favoring unnaturally short translations.

Q15: What is the Peephole Connection in LSTMs? Variants

Answer: Gers & Schmidhuber (2000) added direct connections from cell state $C_{t-1}$ to the gate controllers ($f_t, i_t, o_t$), allowing the gates to inspect the cell state directly when deciding whether to open or close.

Q16: How do you handle vanishing gradients in multi-layer deep RNNs? Architectures

Answer: Add residual skip connections across recurrent layers: $h_t^{[l+1]} = \text{RNN}(h_t^{[l]}) + h_t^{[l]}$, or apply Layer Normalization across the hidden units (Ba et al., 2016).

Q17: Why is Gradient Clipping mandatory when training vanilla RNNs? Stability

Answer: In recurrent loops, exploding gradients cause instantaneous parameter updates into astronomical values, causing weights to turn into NaN. Clipping gradient norm bounds max update step, ensuring stable trajectories around steep cliff edges.

Q18: What is Top-k vs. Top-p (Nucleus) Sampling in decoder generation? Decoding

Answer: Top-$k$ samples only from the $k$ most probable tokens. Top-$p$ (Nucleus sampling, Holtzman et al. 2019) dynamically selects the smallest set of tokens whose cumulative probability exceeds $p$ (e.g. 0.90), expanding the candidate set when probability is diffuse and narrowing it when confident.

Q19: Can an LSTM remember information indefinitely? Theory

Answer: In theory, if $f_t = 1.0$ and $i_t = 0$, $C_t = C_{t-1}$ remains constant indefinitely. In practice, finite 32-bit floating point precision errors, slight non-zero inputs, and small gate perturbations cause memory drift over hundreds of steps.

Q20: What is Attention Map visualization used for? Interpretability

Answer: Plotting the $M \times N$ attention matrix $\alpha_{t, i}$ as a heatmap reveals which source words the model attended to when generating each target word, providing interpretability into grammatical reordering (e.g. French noun-adjective inverted to English adjective-noun).

Q21: Why is Tanh used as the candidate activation in LSTMs instead of ReLU? Concept

Answer: $\tanh$ bounds candidate values strictly to $(-1, 1)$, preventing cell state values from growing without bound when integrated additively across hundreds of time steps ($C_t = C_{t-1} + \tilde{C}_t$). ReLU is unbounded and would cause cell state values to explode.

Q22: What is the computational complexity of the Attention mechanism with $M$ source tokens and $N$ target tokens? Complexity

Answer: For each of the $N$ target tokens, the model computes dot products with all $M$ source tokens: total alignment compute is $O(M \cdot N \cdot H)$, which scales quadratically with sequence length.

Q23: How does Self-Attention differ from Cross-Attention? Attention

Answer: In Cross-Attention, queries come from the decoder while keys and values come from the encoder. In Self-Attention, queries, keys, and values all come from the same sequence, allowing tokens to attend to other tokens within the same sentence.

Q24: What is Repetition Penalty in sequence generation? Decoding

Answer: Decoders often get trapped in repetitive loops (*"and then and then and then"*). Repetition penalty discounts the logits of tokens that have already appeared in the generated prefix by dividing positive logits by $\theta > 1$ or multiplying negative logits by $\theta$, penalizing repeated text.

Q25: Why did the Transformer completely replace recurrent networks in NLP? Evolution

Answer: Transformers discarded the recurrent temporal loop entirely, computing self-attention across all tokens simultaneously. This allows massive GPU parallelization across millions of tokens, eliminating BPTT serial bottlenecks and allowing models to scale to billions of parameters.

Q26: What is Teacher Forcing and what is the Exposure Bias crisis? Training

Answer: In standard Seq2Seq training with Teacher Forcing, the ground-truth token $y_{t-1}^*$ is fed as input to the decoder at step $t$ rather than the model's own predicted token $\hat{y}_{t-1}$. This stabilizes early gradient flow. However, it creates Exposure Bias: at inference time, the model is exposed only to its own generated tokens. If it generates a single suboptimal token early on, the model encounters a state space it never saw during training, causing catastrophic error compounding. Bengio's Scheduled Sampling mitigates this by gradually annealing the probability of using ground truth tokens from $1.0$ down to $0.0$ as training progresses.

Q27: How does PackedSequence optimize RNN training throughput in PyTorch? Performance

Answer: Padding variable-length sentences with `` tokens wastes memory and FLOPs processing dummy tokens across the entire batch length $L_{\max}$. PyTorch's pack_padded_sequence sorts sentences in descending order of length, strips padding tokens, and flattens active tokens into contiguous memory blocks indexed by batch sizes per timestep. CuDNN's fused CUDA kernels process only the active tokens at each unroll step, reducing VRAM usage and boosting GPU tensor core utilization by $2\times - 4\times$.
