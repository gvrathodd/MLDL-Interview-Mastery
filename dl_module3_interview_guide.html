Why Dense Layers Fail on Vision & Convolutional Physics

Spatial locality, translation equivariance, and the catastrophic parameter explosion of fully connected layers.

🖼️ The Catastrophic Parameter Explosion of MLP on Images

Suppose you want to process a standard smartphone photograph ($1000 \times 1000$ pixels, RGB channels = $3,000,000$ inputs) using a standard Fully Connected (Dense) hidden layer with just $1,000$ neurons:

$$\text{Number of Weights} = 3,000,000 \times 1,000 = \mathbf{3,000,000,000 \text{ parameters!}}$$

At 4 bytes per FP32 parameter, this single layer requires 12 GB of VRAM just to store its weight matrix! A model with billions of parameters on raw pixels would overfit instantly on any realistic dataset.

1. The Two Inductive Biases of Computer Vision

Biological & Physical Principles of Visual Data:

  1. Spatial Locality (Pixels Near Each Other Are Correlated):
    A pixel at $(x, y)$ shares meaningful semantics with adjacent pixels $(x+1, y)$ (forming edges, textures, and patches). It has virtually zero direct correlation with a pixel at the opposite corner of the image.
    CNN Solution: Local receptive field kernels ($3\times 3$ or $5\times 5$) connect neurons only to local neighborhoods.

  2. Translation Equivariance (Features Are Universal Across Space):
    An edge, eye, or cat's ear is the same visual feature whether it appears in the top-left, center, or bottom-right corner of an image.
    CNN Solution: Weight Sharing! The exact same $3\times 3$ filter kernel slides across every spatial location in the image, reducing parameter count from billions to just $3 \times 3 = 9$ numbers!

2. Translation Equivariance vs. Translation Invariance

🔥 The Classic FAANG Interview Distinction:

  • Translation Equivariance (Convolutions):
    If the input shifts by $(\Delta x, \Delta y)$, the feature map representation shifts by the exact same $(\Delta x, \Delta y)$: $$f(g(x)) = g(f(x))$$ Convolutional layers are equivariant: shifting a cat in the image shifts the activation peak in the feature map.
  • Translation Invariance (Pooling / Global Average Pooling):
    If the input shifts, the output prediction does not change at all: $$f(g(x)) = f(x)$$ Max Pooling and Global Average Pooling provide invariance: the final classifier predicts "Cat" regardless of where the cat sits in the frame.

2D Convolution Math, Output Shapes & Parameter Counting

Cross-correlation vs. convolution, the universal spatial output formula, and exact layer parameter calculation.

📐 Cross-Correlation vs. True Convolution

In pure mathematics, a convolution flips the kernel horizontally and vertically before sliding:

$$(I * K)(i, j) = \sum_m \sum_n I(i - m, j - n) K(m, n)$$

In deep learning libraries (PyTorch, TensorFlow, CUDA cuDNN), the kernel is NOT flipped. We compute the Cross-Correlation:

$$S(i, j) = (I \star K)(i, j) = \sum_m \sum_n I(i + m, j + n) K(m, n)$$

Since the weights $K$ are learned via backpropagation, flipping is mathematically irrelevant — the network simply learns the mirrored weights directly!

1. The Universal Output Shape Formula

The Dimension Equation:

Given input spatial dimension $W_{\text{in}}$, kernel size $K$, padding $P$, and stride $S$:

$$\mathbf{W_{\text{out}} = \left\lfloor \frac{W_{\text{in}} - K + 2P}{S} \right\rfloor + 1}$$
  • Valid Padding ($P = 0$): No padding. Output shrinks: $W_{\text{out}} = \lfloor \frac{W_{\text{in}} - K}{S} \rfloor + 1$.
  • Same Padding (Preserve Spatial Dimensions when $S = 1$):
    To ensure $W_{\text{out}} = W_{\text{in}}$, set padding: $$\mathbf{P = \frac{K - 1}{2}} \quad (\text{requires odd kernel size, e.g. } K=3 \implies P=1, \; K=5 \implies P=2)$$

2. Parameter Counting for a Convolutional Layer

Formula for Total Trainable Parameters:

Let a Conv2D layer have $C_{\text{in}}$ input channels, $C_{\text{out}}$ output filters, kernel dimensions $K_h \times K_w$, and bias terms:

$$\mathbf{\text{Parameters} = \Big( (K_h \times K_w \times C_{\text{in}}) + 1 \Big) \times C_{\text{out}}}$$

Concrete Interview Example:

Question: How many parameters are in a Conv2D layer with $C_{\text{in}} = 64$, $C_{\text{out}} = 128$, kernel $3\times 3$, with bias enabled?

Calculation:

  • Weights per filter = $3 \times 3 \times 64 = 576$
  • Bias per filter = $1$
  • Total per filter = $576 + 1 = 577$
  • Total for 128 filters = $577 \times 128 = \mathbf{73,856 \text{ parameters}}$

Notice that parameter count is completely independent of input image size $(H, W)$! A $32 \times 32$ image and a $4000 \times 4000$ image use the exact same 73,856 weights.

Receptive Field (RF): Physics & Recursive Math

What a deep neuron sees: Jump factors, stride scaling, and worked step-by-step calculations.

👁️ What is the Receptive Field?

The Receptive Field (RF) of a neuron in layer $l$ is the spatial area in the original input image that influences that neuron's activation. If an object is 100 pixels wide, a neuron whose receptive field is only 15 pixels cannot recognize the object — it can only see a small patch of fur or metal!

1. Recursive Mathematical Equations for Receptive Field

The Universal Recursive Tracking System:

For each layer $l = 1, \dots, L$ with kernel size $k_l$ and stride $s_l$:

  1. Cumulative Stride / Jump ($j_l$): Distance between consecutive features in the feature map relative to input: $$j_0 = 1, \quad \mathbf{j_l = j_{l-1} \cdot s_l}$$
  2. Receptive Field Size ($RF_l$): $$RF_0 = 1, \quad \mathbf{RF_l = RF_{l-1} + (k_l - 1) \cdot j_{l-1}}$$

2. Worked Step-by-Step Receptive Field Walkthrough

Tracking Receptive Field Across a 3-Layer Network:

  • Input: $RF_0 = 1, \; j_0 = 1$.
  • Layer 1 (Conv2D: $k_1 = 3, \; s_1 = 1$):
    $RF_1 = RF_0 + (k_1 - 1)j_0 = 1 + (3 - 1)(1) = 1 + 2 = \mathbf{3}$
    $j_1 = j_0 \cdot s_1 = 1 \cdot 1 = \mathbf{1}$
  • Layer 2 (MaxPool: $k_2 = 2, \; s_2 = 2$):
    $RF_2 = RF_1 + (k_2 - 1)j_1 = 3 + (2 - 1)(1) = 3 + 1 = \mathbf{4}$
    $j_2 = j_1 \cdot s_2 = 1 \cdot 2 = \mathbf{2}$
  • Layer 3 (Conv2D: $k_3 = 3, \; s_3 = 1$):
    $RF_3 = RF_2 + (k_3 - 1)j_2 = 4 + (3 - 1)(2) = 4 + 4 = \mathbf{8}$
    $j_3 = j_2 \cdot s_3 = 2 \cdot 1 = \mathbf{2}$

Conclusion: A single scalar activation in the output of Layer 3 is influenced by an $\mathbf{8 \times 8}$ pixel patch in the original image!

3. Effective vs. Theoretical Receptive Field (Luo et al., NeurIPS 2016)

💡 The Gaussian Distribution of Attention:

Although the theoretical receptive field grows linearly with depth, Luo et al. proved that the Effective Receptive Field (ERF) — pixels that actually have non-negligible gradient impact — follows a 2D Gaussian distribution centered at the middle of the theoretical field. Pixels near the boundary have virtually zero impact! Skip connections (ResNets) expand the ERF significantly.

Specialized Convolutions: 1x1, Dilated & Transposed

Channel projection physics, exponential receptive field expansion, and pixel upsampling mechanics.

🔧 Beyond Standard Convolutions

Standard spatial convolutions mix spatial information ($H, W$) and channel information ($C$) simultaneously. Modern computer vision relies on specialized convolutional variants that decouple spatial and channel transformations.

1. 1x1 Convolutions: Cross-Channel Pooling (Lin et al., Network-in-Network)

How a 1x1 Filter Operates:

A $1\times 1$ convolution has kernel spatial size $1 \times 1$. It operates on a single pixel location $(h, w)$ across all $C_{\text{in}}$ channels simultaneously:

$$y(h, w, k) = \sum_{c=1}^{C_{\text{in}}} W_{c, k} \cdot x(h, w, c) + b_k$$

Two Core Applications:

  1. Dimensionality Reduction (Bottlenecks): Projecting $C_{\text{in}} = 256 \to C_{\text{out}} = 64$ drastically reduces compute before expensive $3\times 3$ or $5\times 5$ convolutions (the foundation of GoogLeNet and ResNet bottlenecks).
  2. Non-Linear Cross-Channel Interaction: Applying ReLU after a $1\times 1$ conv adds depth and non-linearity without altering spatial dimensions.

2. Dilated (Atrous) Convolutions: Exponential Receptive Field

Mechanism (Yu & Koltun, 2015 / DeepLab):

A dilated convolution inserts $(d - 1)$ zeros (holes) between kernel elements, where $d$ is the dilation rate:

$$\mathbf{K_{\text{effective}} = K + (K - 1)(d - 1)}$$
  • For $K = 3$ with $d = 1$: Effective kernel is $3 \times 3$ ($RF = 3$).
  • For $K = 3$ with $d = 2$: Effective kernel is $5 \times 5$ ($RF = 5$), with only 9 active parameters!
  • For $K = 3$ with $d = 4$: Effective kernel is $9 \times 9$ ($RF = 9$), with only 9 active parameters!

Why It Matters for Segmentation: Standard pooling downsamples resolution, destroying fine boundaries. Dilated convolutions expand receptive field exponentially without reducing spatial resolution or adding any extra parameters!

3. Transposed Convolutions (Deconvolution / Fractional Stride)

🚨 The Checkerboard Artifact Hazard:

Transposed convolutions are used to upsample feature maps in generative models (GANs, VAEs) and segmentation networks (U-Net). However, when kernel size is not evenly divisible by stride (e.g. $K=3, S=2$), overlapping receptive field regions produce uneven accumulation of pixel intensities — creating visible checkerboard artifacts in generated images!

Production Fix (Odena et al., 2016): Replace transposed convolutions with Bilinear/Nearest-Neighbor Upsampling followed by a standard Conv2D.

ConvNet Evolution: From AlexNet to VGG & Inception

The shift from large filters to micro-architectures, VGG's 3x3 parameter proof, and multi-scale Inception.

🏛️ The Milestones of Computer Vision

The history of modern deep learning began in 2012 when AlexNet crushed the ImageNet competition, reducing top-5 classification error from 26% to 15.3%. Subsequent architectures refined filter sizing, depth, and computational efficiency.

1. AlexNet Breakthroughs (Krizhevsky, Sutskever & Hinton, 2012)

Key Innovations that Sparked the Deep Learning Revolution:

  • ReLU Activation: Replaced Sigmoid/Tanh, accelerating training by 6x and preventing gradient saturation.
  • GPU Acceleration: Implemented in custom CUDA code on two 3GB NVIDIA GTX 580 GPUs.
  • Dropout ($p=0.5$): Prevented severe overfitting in the massive 4096-neuron fully connected layers.
  • Heavy Data Augmentation: Random $224\times 224$ crops, horizontal flips, and PCA color jittering.

2. Mathematical Proof: Why VGG Stacks $3\times 3$ Filters (Simonyan & Zisserman, 2014)

Theorem: Two stacked $3\times 3$ convs equal one $5\times 5$ conv in receptive field, but save 28% parameters!

Step 1: Receptive Field Equivalence:

  • Layer 1 ($3\times 3, s=1$): $RF_1 = 3$.
  • Layer 2 ($3\times 3, s=1$): $RF_2 = RF_1 + (3 - 1) = 3 + 2 = \mathbf{5}$.

Thus, two consecutive $3\times 3$ convolutions cover the exact same $5\times 5$ spatial receptive field as a single $5\times 5$ filter!

Step 2: Parameter Comparison for $C$ Channels:

  • Single $5\times 5$ Convolution: $$\text{Params} = 5 \times 5 \times C \times C = \mathbf{25 C^2}$$
  • Two Stacked $3\times 3$ Convolutions: $$\text{Params} = 2 \times (3 \times 3 \times C \times C) = 2 \times 9 C^2 = \mathbf{18 C^2}$$

Ratio: $\frac{18 C^2}{25 C^2} = \mathbf{0.72}$ — a 28% reduction in parameters and compute!

Furthermore, stacking two layers introduces two non-linear ReLU activations instead of one, giving the network higher representational power! (Three $3\times 3$ convs cover $7\times 7$ while saving 45% compute: $27 C^2$ vs $49 C^2$).

3. GoogLeNet / Inception (Szegedy et al., 2014)

💡 The Inception Philosophy: "Multi-Scale Processing"

Instead of guessing whether to use a $1\times 1$, $3\times 3$, or $5\times 5$ filter at layer $l$, GoogLeNet runs all of them in parallel and concatenates their outputs along the channel dimension!

The Bottleneck Trick: To prevent computational explosion, GoogLeNet places a $1\times 1$ conv before the $3\times 3$ and $5\times 5$ convs to compress channel dimension, allowing a 22-layer network to run with only 5 million parameters (compared to AlexNet's 60M and VGG's 138M)!

ResNet: Deep Residual Learning & The Gradient Highway

Kaiming He et al. (2015), the degradation crisis, identity shortcuts, and the mathematical gradient highway proof.

🛑 The Degradation Problem: Why Deeper Plain Networks Fail

Before 2015, machine learning researchers believed that adding more layers to a plain network was always beneficial. But experiments revealed a paradox:

A 56-layer plain network performed WORSE on both training and test error than a 20-layer network!

This was NOT overfitting (because training error was also worse). It was the optimization degradation problem: Standard optimization algorithms simply could not push gradients through 50+ stacked non-linear layers without signal attenuation.

1. The Residual Formulation

The Core Hypothesis:

Instead of hoping a stack of layers fits an underlying mapping $\mathcal{H}(x)$, we explicitly let the layers fit a residual mapping $\mathcal{F}(x) \equiv \mathcal{H}(x) - x$:

$$\mathbf{y = \mathcal{F}(x, \{W_i\}) + x}$$

Where $x$ is the input fed directly via an Identity Shortcut Connection.

Why is this easier to learn? If an identity mapping is optimal, it is much easier for weights to decay toward zero ($\mathcal{F}(x) \to 0$) than to learn an identity transformation $W x \approx x$ through multiple non-linear layers!

2. Mathematical Proof of the Uninterrupted Gradient Highway

Theorem: Gradients flow directly back from layer $L$ to any earlier layer $l$ without multiplicative decay.

Consider the recursive residual relation for any deep layer $L$ given earlier layer $l$:

$$x_L = x_l + \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i)$$

By the chain rule, the gradient of the scalar loss $\mathcal{L}$ with respect to activation $x_l$ is:

$$\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \frac{\partial x_L}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left( \frac{\partial}{\partial x_l} \left[ x_l + \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i) \right] \right)$$ $$\mathbf{\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left( \mathbf{I} + \frac{\partial}{\partial x_l} \sum_{i=l}^{L-1} \mathcal{F}(x_i, W_i) \right)}$$

The Punchline of the Formula:

  • Look at the term $\mathbf{I}$ (the identity matrix): The gradient $\frac{\partial \mathcal{L}}{\partial x_L}$ is multiplied by $\mathbf{I}$ and transferred directly to $\frac{\partial \mathcal{L}}{\partial x_l}$ without passing through any weight matrices!
  • Even if the second term $\frac{\partial}{\partial x_l} \sum \mathcal{F}$ vanishes completely to zero, the gradient is guaranteed to flow through the $+ \mathbf{I}$ highway!
  • This mathematically proves why ResNet-152, ResNet-1001, and modern Transformers (which use residual connections) train smoothly without gradient vanishing! $\blacksquare$

MobileNets & Depthwise Separable Convolutions

Howard et al. (2017), spatial vs. channel decoupling, and the complete 8-9x FLOPs reduction proof.

📱 Edge AI & Mobile Computation Constraints

Running ResNet-50 on an iPhone or embedded drone processor drains the battery and exceeds thermal limits. MobileNet revolutionized lightweight deep learning by breaking standard convolution into two decoupled steps: spatial filtering and channel projection.

1. The Two-Step Factorization

A Standard Convolution mixes space and channels simultaneously:

$$\text{Standard Conv: Computes spatial filtering AND channel combination in a single step.}$$

Depthwise Separable Convolution splits this into:

  1. Step 1: Depthwise Convolution:
    Applies a single $K \times K$ filter per input channel independently (computes spatial patterns without channel mixing). Output has $C_{\text{in}}$ channels.
  2. Step 2: Pointwise Convolution ($1\times 1$ Conv):
    Applies $C_{\text{out}}$ filters of size $1 \times 1 \times C_{\text{in}}$ to compute linear combinations across channels.

2. Mathematical Proof: The 8-9x Compute Reduction

Computational Cost (FLOPs) Comparison:

Let input be $D_F \times D_F \times M$ and output be $D_F \times D_F \times N$ with kernel size $D_K \times D_K$ (assuming stride 1 with same padding):

1. FLOPs of Standard Convolution:

$$\text{Cost}_{\text{standard}} = D_K \times D_K \times M \times N \times D_F \times D_F$$

2. FLOPs of Depthwise Separable Convolution:

$$\text{Cost}_{\text{depthwise}} = D_K \times D_K \times M \times D_F \times D_F$$ $$\text{Cost}_{\text{pointwise}} = 1 \times 1 \times M \times N \times D_F \times D_F = M \times N \times D_F \times D_F$$ $$\text{Cost}_{\text{separable}} = (D_K \times D_K \times M \times D_F^2) + (M \times N \times D_F^2)$$

3. The Compute Reduction Ratio:

$$\mathbf{\frac{\text{Cost}_{\text{separable}}}{\text{Cost}_{\text{standard}}} = \frac{D_K^2 \cdot M \cdot D_F^2 + M \cdot N \cdot D_F^2}{D_K^2 \cdot M \cdot N \cdot D_F^2} = \frac{D_K^2 + N}{D_K^2 \cdot N} = \frac{1}{N} + \frac{1}{D_K^2}}$$

Evaluation for Standard $3\times 3$ Filters ($D_K = 3$):

Since output channels $N$ is typically large ($N \ge 64$), $\frac{1}{N} \approx 0$:

$$\mathbf{\text{Ratio} \approx \frac{1}{3^2} = \frac{1}{9} \approx \mathbf{0.11}}$$

Result: Depthwise separable convolution achieves an 8x to 9x reduction in computational cost with only $\approx 1\%$ loss in ImageNet top-1 accuracy! $\blacksquare$

Modern Vision Architectures: ResNeXt & ConvNeXt

Cardinality, split-transform-merge, and modernizing CNNs to match Vision Transformers.

🏎️ The Modern Evolution of ConvNets

While Vision Transformers (ViT) captured headlines in 2020-2021, modern ConvNet engineering demonstrated that convolutional architectures can match or exceed Transformer accuracy when modern training recipes are applied.

1. ResNeXt & The Power of Cardinality (Xie et al., 2017)

Cardinality (The Number of Paths):

ResNeXt introduces a third dimension beyond depth and width: Cardinality ($C$) — the number of parallel grouped transformation paths in a block.

$$\mathbf{y = x + \sum_{i=1}^C \mathcal{T}_i(x)}$$

Interview Takeaway: Increasing cardinality is strictly more effective at boosting classification accuracy than increasing depth or width while maintaining the exact same parameter budget and FLOP count.

2. ConvNeXt: Modernizing CNNs for the 2020s (Liu et al., CVPR 2022)

How Meta Modernized ResNet-50 into ConvNeXt:

  1. Macro Design: Changed stage compute ratio from $(3, 4, 6, 3)$ to $(3, 3, 9, 3)$ (matching Swin Transformer).
  2. Inverted Bottleneck: Widened hidden channels $4x$ in the middle rather than compressing them.
  3. Larger Kernel Size ($7\times 7$ Depthwise): Replaced $3\times 3$ convs with non-overlapping $7\times 7$ depthwise convs, mimicking ViT self-attention receptive field!
  4. Micro-Design Tweaks:
    • Replaced ReLU with GELU.
    • Fewer activation and normalization layers (only 1 per block instead of 3).
    • Replaced BatchNorm with LayerNorm.
    • Separate downsampling layers (patches).

Outcome: ConvNeXt achieved 87.8% ImageNet top-1 accuracy, outperforming Swin Transformers while retaining CNN inference efficiency!

Object Detection: IoU, NMS, Faster R-CNN & YOLO

Bounding box regression, anchor boxes, two-stage vs. single-stage detectors, and mAP evaluation.

📦 Classification vs. Object Detection

Classification asks: "What is in this image?" (single label output). Object Detection asks: "Where are the objects, and what are their categories?" (predicting coordinates $[x, y, w, h]$ and class labels for multiple overlapping objects).

1. Core Metrics & Algorithms: IoU & NMS

A. Intersection over Union (IoU / Jaccard Index):

$$\mathbf{\text{IoU} = \frac{\text{Area}(B_1 \cap B_2)}{\text{Area}(B_1 \cup B_2)} = \frac{\text{Area of Overlap}}{\text{Area of Union}}}$$

Measures how closely a predicted bounding box matches ground truth. An IoU $\ge 0.50$ is classically considered a True Positive.


B. Non-Maximum Suppression (NMS) Algorithm:

A detection network proposes thousands of overlapping candidate boxes for a single object. NMS prunes duplicates:

  1. Discard all candidate boxes with class confidence score $< \text{threshold}_{\text{conf}}$.
  2. Select the box $B^*$ with the highest remaining confidence score and output it.
  3. Calculate IoU between $B^*$ and all other remaining boxes. Discard any box where $\text{IoU}(B^*, B_i) > \text{threshold}_{\text{IoU}}$ (typically $0.45$).
  4. Repeat until no candidate boxes remain.

Segmentation: FCN, U-Net & RoIAlign in Mask R-CNN

Pixel-level classification, encoder-decoder skip connections, and eliminating quantization misalignment.

🎨 Semantic vs. Instance vs. Panoptic Segmentation

  • Semantic Segmentation: Assigns every pixel a category label (e.g. all pedestrians are colored red as one blob).
  • Instance Segmentation: Segments each distinct object individual (Pedestrian 1 is red, Pedestrian 2 is blue).
  • Panoptic Segmentation: Combines both semantic (stuff: sky, road) and instance (things: cars, people).

1. U-Net Architecture (Ronneberger et al., 2015)

Why U-Net Dominates Biomedical Imaging:

U-Net consists of a contracting path (encoder) and an expansive path (decoder), forming a U-shape:

  1. Encoder Path: Repeated $3\times 3$ convolutions and MaxPool operations to capture high-level semantic context.
  2. Decoder Path: Upsampling layers to restore high-resolution pixel coordinates.
  3. Skip Connections (The Core Innovation): Concatenates high-resolution low-level feature maps directly from the encoder to the corresponding decoder layer!
    Why this is essential: Deep encoders lose precise spatial boundary locations. Skip connections transmit fine-grained edge and texture coordinates directly across the network, enabling pixel-perfect boundary segmentation!

2. RoIPool vs. RoIAlign (He et al., Mask R-CNN 2017)

🚨 The Quantization Misalignment Bug in RoIPool:

In Fast R-CNN, RoIPool extracts fixed-size feature maps from candidate boxes by applying floor/round quantization ($\lfloor x/16 \rfloor$).

  • Rounding coordinates creates a spatial quantization error of up to 1-2 pixels on the feature map.
  • Multiplied by a $16x$ downsampling stride, this creates a 16 to 32 pixel misalignment on the original image — catastrophic for pixel-level masks!

The RoIAlign Solution:

RoIAlign completely eliminates rounding! It uses Bilinear Interpolation at four sampling locations inside each bin, computing exact continuous fractional coordinates. This single modification boosted mask accuracy significantly.

25+ High-Frequency FAANG Interview Questions: Computer Vision

Technical screening and deep architectural design questions asked at Meta, Apple, Google, and Waymo.

Part 1: Convolutional Fundamentals & Shapes

Q1: How many trainable parameters are in a Conv2D layer with 128 input channels, 256 output channels, and a 3x3 kernel (with bias)? Core

Answer: Each filter has size $3 \times 3 \times 128$ weights $+ 1$ bias $= 1,152 + 1 = 1,153$ parameters. For 256 output filters: $1,153 \times 256 = \mathbf{295,168 \text{ parameters}}$. Notice that image spatial dimensions $(H, W)$ do not affect parameter count.

Q2: What is the output spatial dimension of an input tensor of size 224x224 passed through a 7x7 conv with stride 2 and padding 3? Math

Answer: Formula: $W_{\text{out}} = \lfloor \frac{W_{\text{in}} - K + 2P}{S} \rfloor + 1$.

Substituting: $W_{\text{out}} = \lfloor \frac{224 - 7 + 2(3)}{2} \rfloor + 1 = \lfloor \frac{224 - 7 + 6}{2} \rfloor + 1 = \lfloor \frac{223}{2} \rfloor + 1 = 111 + 1 = \mathbf{112 \times 112}$.

Q3: What is the difference between Translation Equivariance and Translation Invariance in CNNs? Concept

Answer:

  • Translation Equivariance: Shifting the input image causes the feature map to shift by the exact same amount ($f(g(x)) = g(f(x))$). Standard convolution layers are translation equivariant.
  • Translation Invariance: Shifting the input image results in no change in the final output ($f(g(x)) = f(x)$). Global Average Pooling and Max Pooling provide translation invariance, ensuring the classified label does not change when an object moves.
Q4: Why does stacking two 3x3 convolutions have the same receptive field as one 5x5 convolution while saving parameters? Math

Answer: Receptive field grows as $RF_2 = RF_1 + (k_2 - 1) = 3 + (3 - 1) = 5$. Parameters for one $5\times 5$ conv on $C$ channels is $25 C^2$. Parameters for two $3\times 3$ convs is $2 \times (9 C^2) = 18 C^2$. This saves 28% parameters while introducing two non-linear ReLU activations instead of one.

Q5: What is a 1x1 convolution used for in CNN architectures? Concept

Answer: Cross-channel linear combination and dimensionality reduction. A $1\times 1$ conv compresses or expands channel dimensions (e.g. $256 \to 64$ in ResNet bottleneck blocks) without altering spatial dimensions, reducing computational cost before expensive spatial convolutions.

Part 2: ResNets & Modern Architectures

Q6: How does ResNet mathematically solve the vanishing gradient problem? Proof

Answer: By using identity shortcut connections: $x_{l+1} = x_l + \mathcal{F}(x_l)$. The gradient is $\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_{l+1}} \left( \mathbf{I} + \frac{\partial \mathcal{F}}{\partial x_l} \right)$. The identity matrix $\mathbf{I}$ creates an uninterrupted gradient highway, allowing gradient signal to flow backwards directly even if the residual weights derivative $\frac{\partial \mathcal{F}}{\partial x_l}$ vanishes to zero.

Q7: What is the degradation problem in plain deep networks, and why is it NOT overfitting? ResNet

Answer: When stacking 50+ plain layers without residual connections, the training error is higher than a 20-layer network. If it were overfitting, training error would be lower. It is an optimization degradation problem caused by severe gradient attenuation through repeated non-linearities.

Q8: Derive the computational FLOPs reduction of Depthwise Separable Convolutions in MobileNet. Derivation

Answer: Standard Conv FLOPs: $K^2 \cdot M \cdot N \cdot D_F^2$. Depthwise Separable FLOPs: $(K^2 \cdot M \cdot D_F^2) + (M \cdot N \cdot D_F^2)$.

Ratio: $\frac{K^2 \cdot M \cdot D_F^2 + M \cdot N \cdot D_F^2}{K^2 \cdot M \cdot N \cdot D_F^2} = \frac{1}{N} + \frac{1}{K^2}$. For $K=3$ and large $N$, the ratio is $\approx \frac{1}{9} \approx \mathbf{0.11}$ — an **8x to 9x reduction in compute**.

Q9: What is Cardinality in ResNeXt and why is it superior to Depth or Width? Architectures

Answer: Cardinality is the number of parallel grouped transformation paths within a block. Xie et al. proved that increasing cardinality yields higher classification accuracy than increasing depth or width while maintaining the exact same FLOPs and parameter budget.

Q10: What modern architectural modifications did ConvNeXt introduce to rival Vision Transformers? Modern CV

Answer: $7\times 7$ depthwise convolutions (matching ViT patch self-attention), inverted bottleneck design, replacing ReLU with GELU, fewer normalizations, replacing BatchNorm with LayerNorm, and separate patchify downsampling layers.

Part 3: Object Detection & Segmentation

Q11: How does Non-Maximum Suppression (NMS) work in object detection? Algorithm

Answer: Discard all boxes below confidence threshold. Pick the highest scoring box $B^*$, save it to final detections, and eliminate all remaining boxes that have $\text{IoU}(B^*, B_i) > \text{threshold}$ (typically 0.45). Repeat until all boxes are processed.

Q12: What is the difference between RoIPool and RoIAlign in Mask R-CNN? Meta CV

Answer: RoIPool rounds/quantizes continuous bounding box coordinates to integer grid bins ($\lfloor x/16 \rfloor$), creating spatial quantization misalignment of 16-32 pixels in original image space. RoIAlign uses bilinear interpolation at continuous fractional coordinates without rounding, preserving pixel-level alignment mandatory for instance segmentation masks.

Q13: Why does U-Net use skip connections between the encoder and decoder? Segmentation

Answer: Successive pooling/downsampling in the encoder captures high-level semantic context but discards fine-grained spatial localization. Skip connections copy high-resolution spatial feature maps directly across from encoder to decoder, allowing the network to assemble sharp, pixel-accurate segmentation boundaries.

Q14: Explain the difference between 1-stage (YOLO) and 2-stage (Faster R-CNN) object detectors. Systems

Answer: Two-stage detectors generate candidate region proposals via an RPN in stage 1, then classify and regress bounding boxes in stage 2 (slower, higher accuracy on small objects). Single-stage detectors treat detection as a single regression problem across a spatial grid in one forward pass (faster, real-time 60+ FPS).

Q15: What causes checkerboard artifacts in transposed convolutions and how do you resolve it? Generative CV

Answer: When kernel size is not divisible by stride in transposed convolutions, overlapping receptive field patches accumulate uneven pixel values. Resolved by replacing transposed convolutions with Nearest-Neighbor or Bilinear interpolation upsampling followed by a standard Conv2D layer.

Q16: What is a Dilated (Atrous) Convolution and why is it used in semantic segmentation? Math

Answer: It inserts $(d-1)$ spaces between kernel elements. For dilation rate $d$, effective kernel size is $K + (K-1)(d-1)$. It expands receptive field exponentially without downsampling spatial resolution or adding any extra parameters, preserving high-resolution boundaries in DeepLab.

Q17: What is mean Average Precision (mAP) in object detection? Metrics

Answer: mAP computes the Area Under the Precision-Recall curve (AP) for each object class, then averages AP across all classes. mAP@0.5 evaluates at IoU threshold 0.50; mAP@0.5:0.95 averages across 10 IoU thresholds from 0.50 to 0.95 in steps of 0.05 (COCO standard).

Q18: How does Global Average Pooling (GAP) prevent overfitting compared to fully connected layers? Architectures

Answer: Replaces giant dense matrices ($7\times 7\times 512 \to 4096 = 100\text{M params}$) by averaging each feature map spatially down to a single scalar ($1\times 1\times 512$). It has zero trainable parameters, preventing overfitting, and enforces direct semantic correspondence between feature maps and category classes.

Q19: What is the Effective Receptive Field (ERF) and why does it matter? Theory

Answer: The theoretical receptive field assumes all pixels inside the window contribute equally. Luo et al. (2016) proved the effective receptive field follows a 2D Gaussian distribution where central pixels have vastly higher influence than boundary pixels.

Q20: Why do Vision Transformers (ViT) require much more training data than CNNs? Transformers vs CNNs

Answer: CNNs have strong hard-coded inductive biases: spatial locality and translation equivariance. Vision Transformers use global self-attention with no innate spatial knowledge — they must learn spatial locality from data. On small datasets (ImageNet-1k), CNNs outperform ViTs; on massive datasets (JFT-300M), ViTs dominate.

Q21: How do anchor boxes help object detection models detect multiple overlapping objects? Detection

Answer: Predefined bounding box templates of diverse aspect ratios (e.g. 1:1, 1:2, 2:1) assigned to each grid cell. They allow a single spatial grid location to detect multiple overlapping objects of different shapes (e.g. a tall standing pedestrian next to a wide horizontal car).

Q22: What is the purpose of auxiliary classifiers in GoogLeNet? Google Classic

Answer: GoogLeNet added intermediate softmax classifier branches at layers 4 and 7 during training. Their losses were scaled by 0.3 and added to the total loss, injecting auxiliary gradients directly into middle layers to combat vanishing gradients before ResNet was invented.

Q23: What is Feature Pyramid Network (FPN) and why is it used? CV Systems

Answer: Combines low-resolution semantically strong deep features with high-resolution semantically weak shallow features via top-down pathways and lateral connections. Constructs multi-scale feature representations, allowing detectors to detect small, medium, and large objects at appropriate resolutions.

Q24: Can Max Pooling be replaced with strided convolutions? Optimization

Answer: Yes. Springenberg et al. (2014, "All Convolutional Net") showed that replacing max pooling with stride-2 convolutions allows the network to learn its own optimal downsampling function rather than hard-coded max operations, with no loss in accuracy.

Q25: What is the difference between Same padding and Valid padding? Basics

Answer: Valid padding applies 0 padding ($P=0$), shrinking the output spatial dimensions. Same padding applies $P = \frac{K-1}{2}$ zero-padding around the border, ensuring output spatial dimensions match input dimensions when stride $S=1$.
